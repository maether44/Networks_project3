 LAGOON VIEW HOTEL - PACKET TRACER BUILD SCRIPT (TeamX_working.pkt)
 CS411 Project 3 - Network Wars, Session 1

HOW TO USE
 1. Place devices (names exactly as below):
      Routers : 3 x 2911            -> R1, R2, R3
      Switches: 4 x 2960-24TT       -> SW1, SW2, SW3, SW4
      PCs     : Staff-PC1, Staff-PC2, Staff-PC3, POS1, POS2, POS3,
                Manager-PC, Admin-PC                    (PC-PT)
      Laptops : Guest-Laptop1, Guest-Laptop2            (Laptop-PT)
      Servers : SRV-WEB, SRV-RES                         (Server-PT)
 2. Cable them using the table in section A.
 3. Open each router/switch -> CLI tab -> press Enter -> type "no" at
    the setup dialog -> paste that device's block from section B.
 4. Set the end-device IPs (section C) and server services (section D).
 5. Wait ~1 minute for OSPF + STP to converge, then run the checks in
    section E. Save as TeamX_working.pkt.
 6. File > Save As TeamX_broken.pkt, then apply the six faults (commands are in the
    answer key), re-run section E to confirm each symptom, and save.

B. DEVICE CONFIGURATIONS (paste from "enable" to "write memory")
---------------------------------------------------------------------

!=============================== R1 ================================
enable
configure terminal
hostname R1
no ip domain-lookup
interface GigabitEthernet0/0
 description Management LAN (SW4)
 ip address 192.168.40.1 255.255.255.0
 no shutdown
interface GigabitEthernet0/1
 description Link to R2
 ip address 10.0.12.1 255.255.255.252
 no shutdown
interface GigabitEthernet0/2
 description Link to R3
 ip address 10.0.13.1 255.255.255.252
 no shutdown
exit
router ospf 1
 router-id 1.1.1.1
 network 192.168.40.0 0.0.0.255 area 0
 network 10.0.12.0 0.0.0.3 area 0
 network 10.0.13.0 0.0.0.3 area 0
 passive-interface GigabitEthernet0/0
end
write memory

!=============================== R2 ================================
enable
configure terminal
hostname R2
no ip domain-lookup
interface GigabitEthernet0/0
 description Trunk to SW1
 no ip address
 no shutdown
interface GigabitEthernet0/0.10
 description VLAN10 STAFF
 encapsulation dot1Q 10
 ip address 192.168.10.1 255.255.255.0
interface GigabitEthernet0/0.20
 description VLAN20 POS
 encapsulation dot1Q 20
 ip address 192.168.20.1 255.255.255.0
interface GigabitEthernet0/0.30
 description VLAN30 GUESTS
 encapsulation dot1Q 30
 ip address 192.168.30.1 255.255.255.0
interface GigabitEthernet0/1
 description Link to R1
 ip address 10.0.12.2 255.255.255.252
 no shutdown
interface GigabitEthernet0/2
 description Link to R3
 ip address 10.0.23.1 255.255.255.252
 no shutdown
exit
ip dhcp excluded-address 192.168.30.1 192.168.30.99
ip dhcp pool GUESTS
 network 192.168.30.0 255.255.255.0
 default-router 192.168.30.1
 dns-server 192.168.50.10
exit
ip access-list extended GUEST-IN
 permit udp any any eq bootps
 permit icmp 192.168.30.0 0.0.0.255 host 192.168.30.1
 permit icmp 192.168.30.0 0.0.0.255 host 192.168.50.10
 permit tcp 192.168.30.0 0.0.0.255 host 192.168.50.10 eq www
 permit udp 192.168.30.0 0.0.0.255 host 192.168.50.10 eq domain
 deny ip any any
exit
ip access-list extended POS-IN
 permit icmp 192.168.20.0 0.0.0.255 host 192.168.20.1
 permit ip 192.168.20.0 0.0.0.255 host 192.168.50.20
 permit icmp 192.168.20.0 0.0.0.255 any echo-reply
 deny ip any any
exit
interface GigabitEthernet0/0.20
 ip access-group POS-IN in
interface GigabitEthernet0/0.30
 ip access-group GUEST-IN in
exit
router ospf 1
 router-id 2.2.2.2
 network 192.168.10.0 0.0.0.255 area 0
 network 192.168.20.0 0.0.0.255 area 0
 network 192.168.30.0 0.0.0.255 area 0
 network 10.0.12.0 0.0.0.3 area 0
 network 10.0.23.0 0.0.0.3 area 0
 passive-interface GigabitEthernet0/0.10
 passive-interface GigabitEthernet0/0.20
 passive-interface GigabitEthernet0/0.30
end
write memory
